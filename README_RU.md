# STL-библиотека релейных модулей · версия 0.2

**11 разновидностей плат, 22 STL. Сгенерировано ChatGPT (OpenAI) по запросу пользователя.** Эта библиотека не связана с производителями аппаратуры и не одобрена ими.

В каталоге `models/` находятся для каждого исполнения:
- `*_PCB_MOUNTING.stl` — плата с моделируемыми техническими отверстиями;
- `*_ASSEMBLY.stl` — плата с моделируемыми компонентами;
- `*_COORDINATES.csv` — координаты модельных компонентов.

**ВНИМАНИЕ!** Большая часть расположения компонентов **реконструирована или оценена**, а не получена из фабричной разводки PCB. Даже число и координаты отверстий у некоторых модулей приблизительные. Эти модели предназначены для предварительного проектирования корпуса, но не для изготовления без проверки физическим модулем.

Размеры задаются в миллиметрах. Начало координат — левый нижний угол нижней поверхности платы. Толщина условно 1,6 мм.

Реальные размеры/обоснования: `data/accuracy_sources.json`, `data/ALL_FEATURE_COORDINATES.csv`; проверка сеток, но не точности измерений: `data/QA_REPORT.json`. Ознакомьтесь с [MODEL_STATUS.md](MODEL_STATUS.md).

Происхождение: STL, таблицы и генератор были созданы ChatGPT (OpenAI), а не извлечены из чужих 3D-моделей. Это указание технологии создания не означает поддержки проекта компанией OpenAI.
