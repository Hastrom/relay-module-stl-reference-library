# Relay module STL reference library · v0.2

**11 example mechanical configurations · 22 STL files · free to use · source disclosed**

A **ChatGPT (OpenAI)-generated** collection of original procedural 3D approximations of Arduino-compatible relay modules, prepared at the request of a user for mechanical planning. It was **not** created or endorsed by Arduino, Seeed Studio, Songle, or any hardware manufacturer.

**Important: the component coordinates are reconstructed/estimated and are NOT verified against manufacturer PCB/CAD files.** Do not treat the files as dimensionally certified replicas.

## Contents

- **Six distinct single-relay reference layouts**: 50 × 26 mm (4-hole and 2-hole), 50.8 × 25.6 mm dual-trigger style, compact 34 × 27 mm, slim 40 × 18 mm, and 4-pin 42 × 24 mm.
- **Multi-relay reference layouts**: 2, 4, 6, 8 and 16 channels.
- Each layout provides `*_PCB_MOUNTING.stl`, `*_ASSEMBLY.stl`, and an individual `*_COORDINATES.csv`.
- `data/accuracy_sources.json` records nominal board dimensions, hole assumptions, provenance URLs and model status.
- `data/QA_REPORT.json` documents mesh checks, **not** measurement against real hardware.
- `data/ALL_FEATURE_COORDINATES.csv` contains individual modeled positions and evidence labels.
- `scripts/generate.py` is the original AI-generated procedural generator adapted for a portable directory layout. Dependencies are in `scripts/requirements.txt`.

## Units and coordinate origin

**Millimeters.** `(0, 0, 0)` is the lower-left corner of the **bottom** of the modeled PCB. PCB thickness is provisionally `1.6 mm`; upper face is `Z = 1.6 mm`. Position in a CSV is the position modeled, **not** an assertion of actual factory placement.

## Accuracy and safety

- Some **overall board dimensions and mounting pitches** are based on publicly reported numeric specifications. Verify the exact product revision and orientation; generic modules vary considerably.
- The position of **relays, headers, terminals, LEDs, optocouplers, etc.** was reconstructed without original factory PCB data. Their spatial envelopes are not verified.
- Mounting-hole **diameters and some centers** are assumed; even documented center-to-center pitches do not establish all absolute coordinates.
- Original manufacturer CAD, schematic drawings, PCB copper patterns and third-party meshes were **not included** in this repository.
- This is **not suitable as-is** for automated machining, hole drilling, mains-voltage safety calculations, creepage/clearance decisions or fabrication without checking a real PCB.

## Build/rebuild

```bash
python -m pip install -r scripts/requirements.txt
python scripts/generate.py
```

The original generator may also produce auxiliary reports/archive files in the generated directory. A rebuild is a procedural approximation, not a verification of factory measurements.
